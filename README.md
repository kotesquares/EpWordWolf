# 誰の文章でしょう？（エピソード人狼風）推測ゲーム

参加者全員がスマートフォンやPCのブラウザから参加し、**ゲームマスター（読み上げ役）なしでホスト含めた全員がプレイヤーとして遊べる**リアルタイム推測ゲームです。

自前のバックエンドサーバーは一切不要！**PeerJS (WebRTC P2P通信)** を採用しているため、静的ファイル（React Single Page Application）をGitHub PagesやVercelにアップロードするだけで、世界中どこからでも無料で遊ぶことができます。

---

## 🌟 主な特徴

1. **GM完全不要システム**: サーバーが自動進行と得点計算を行うため、部屋を作成したホストも一プレイヤーとして対等に参加できます。
2. **白基調のモダンUI**: スマホの縦長画面に最適化された清潔感のある白基調＆カードUIデザイン。
3. **お題ガチャ＆制限時間調整**: 「IF・妄想」「秘密・黒歴史」「こだわり」など豊富なプリセットお題を搭載。
4. **リアルタイム進行**: 「◯/◯名が回答入力完了」などがリアルタイムで全プレイヤーの画面に同期。
5. **スリリングなスコアロジック**:
   - **的中ポイント**: 誰の文章かを正しく見破ったら `+100 pt`
   - **かく乱（騙し）ポイント**: 自分の文章で他プレイヤーを騙せたら（自分だとバレずに他の人を選ばせたら） 1票につき `+50 pt`
   - **完全隠蔽ボーナス**: 自分の文章を誰も当てることができなかったら `+100 pt`
6. **QRコード＆招待リンク簡単共有**: 招待URLのコピーやQRコード読み取りで簡単に部屋へ合流可能。

## 🚀 ローカル環境での起動手順

### 必要な環境
- Node.js (v18 以上推奨)
- npm

### 手順

1. **パッケージのインストール**
   ```bash
   npm install
   ```

2. **開発サーバーの起動**
   ```bash
   npm run dev
   ```
   起動後、ブラウザで表示されるURL（例: `http://localhost:5173` またはネットワークIP `http://192.168.x.x:5173`）にアクセスしてください。

3. **複数端末・複数タブでのプレイ**
   - 同じPCで複数のシークレットウィンドウを開くか、スマホを同じWi-Fiに接続してスマホのブラウザからアクセスすると、リアルタイムでマルチプレイを体験できます。

## 📦 Cloudflare Pages へのデプロイ手順（完全サーバーレス・爆速配信）

本アプリは自前サーバー不要の SPA（Single Page Application）なので、**Cloudflare Pages** と非常に相性が良く、完全無料で世界中に爆速公開できます。

### デプロイ手順

1. **GitHubへコードをPush**
   ```bash
   git push -u origin main
   ```

2. **Cloudflare ダッシュボードに接続**
   - [Cloudflare Dashboard](https://dash.cloudflare.com/) にログイン。
   - 左メニューから **Workers & Pages** ➔ **作成 (Create)** ➔ **Pages** タブを開く。
   - **「GitHubに接続 (Connect to GitHub)」** を選択し、リポジトリ `kotesquares/EpWordWolf` を選択。

3. **ビルド設定**
   - **フレームワーク プリセット**: `Vite`
   - **ビルド コマンド**: `npm run build`
   - **ビルド出力ディレクトリ**: `dist`

4. **「保存してデプロイ」を実行**
   - 数十秒でデプロイが完了し、`https://epwordwolf.pages.dev` のような公開URLが発行されます！
   - 以降は GitHub に `git push` するだけで自動的に最新版へ更新されます。

## 🎮 ゲームの流れ

1. **ルーム作成・参加 (Lobby)**
   - ホスト：プレイヤー名を入力し、「部屋を作る」を選択。お題（自由入力またはお題ガチャ）と回答制限時間を設定。
   - ゲスト：プレイヤー名と発行された「ルームコード (数字4桁)」を入力して参加。
2. **フェーズ 1：お題の入力 (Answer)**
   - 表示されたお題に対する自分の回答/エピソードを匿名で入力して送信。
   - 自分だとバレないように書き方を工夫するのも戦略です。
3. **フェーズ 2：推測・投票 (Guess)**
   - 集まった回答が1つずつ匿名で画面に表示されます。
   - 「誰が書いた文章か」を予想して全プレイヤーから選択・投票！
4. **フェーズ 3：結果発表・スコア集計 (Result)**
   - 各エピソードの本当の作者と全員の投票内容を一斉開示。
   - 「的中ポイント」と「かく乱ポイント」が集計され、最終ランキングを発表！
   - 「お題を変えてもう一度遊ぶ」ボタンでそのまま連続プレイ可能。
